These are web-based application for learning English.  
The application interface is similar to [Duolingo](https://www.duolingo.com/).   
The application was created for teaching web programming technologies.

## 🛠️ Technology stack

**Next.js 14**   
**Typescript**   
**Tailwind CSS**  
**Neon + PostgreSQL**    
**Clerk Auth**
